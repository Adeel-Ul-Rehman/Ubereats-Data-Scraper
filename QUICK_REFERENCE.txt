# ============================================================================
# TROUBLESHOOTING
# ============================================================================

Problem: "playwright not found"
Solution: pip install playwright

Problem: "chromium not installed"
Solution: playwright install chromium

Problem: No restaurants found
Solution: 
  1. Let browser open
  2. Manually select city in browser
  3. Wait for restaurants to load
  4. Come back to terminal

Problem: Slow performance
Solution:
  - Reduce SCROLL_PAUSE (1.0 → 0.5)
  - Reduce BROWSER_TIMEOUT
  - Check internet connection

Problem: Getting blocked
Solution:
  - Scraper has anti-detection built-in
  - If blocked, try again later
  - Use different states to spread load

# ============================================================================
# USING THE DATA FOR ML
# ============================================================================

import pandas as pd

# Load
df = pd.read_csv('ubereats_data/restaurants_TX_20260421.csv')

# Explore
print(df.head())
print(df.info())
print(df.describe())

# Clean
df = df.dropna(subset=['Name', 'Address'])
df = df[df['Rating'] > 0]

# Stats
print(f"Restaurants: {len(df)}")
print(f"Avg rating: {df['Rating'].mean():.2f}")
print(f"Avg reviews: {df['Reviews'].mean():.0f}")

# Feature engineering
df['review_score'] = df['Rating'] * df['Reviews']
df['review_category'] = pd.cut(df['Reviews'], bins=[0, 100, 500, 1000, 999999], 
                                labels=['New', 'Popular', 'Very Popular', 'Highly Rated'])

# Save for training
df[['Name', 'Address', 'Rating', 'Reviews']].to_csv('clean_restaurants.csv', index=False)
